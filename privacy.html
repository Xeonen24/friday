Friday privacy policy

Last updated: 17 November 2026

Who uses Friday

Friday is a personal assistant that runs on its owner's own PC. Only the owner signs in. It is not offered to anyone else.

Google data Friday uses

  • Google Calendar: reads events, adds and edits events when the owner asks. Friday never deletes events.
  • Gmail: reads messages to announce and summarise them, and saves drafts the owner asks for. A draft is sent only after the owner reviews it and says to send it. Friday never deletes, trashes or marks mail as read.
  • Google Contacts: read only, to find names, numbers, emails and birthdays.

Where the data goes

All data stays on the owner's PC, in a local database. Nothing is sold, shared, sent to other servers or used for advertising. The language model runs locally on the same PC; Google data is not sent to any AI service.

Google API Services User Data Policy

Friday's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the local database removes all stored copies.
